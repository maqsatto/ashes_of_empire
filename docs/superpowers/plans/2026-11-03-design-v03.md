# Ashes of Empires v0.3 playable design implementation

**Goal:** Implement the supplied DesignBook as a playable multi-country 1924 scenario with distinct routes and reciprocal diplomacy.
**Architecture:** Native HOI4 focus trees, events, decisions, ideas, technology and doctrine effects. Python authoring helpers generate deterministic UTF-8 scripts and BOM localization; they are development tools, not runtime dependencies. Scenario setup uses verified installed state/tag/province data; unspecified borders are provisional fixtures, never new historical canon.
**Tech Stack:** Installed HOI4 1.19.3.0.c01a, Clausewitz scripts, Python 3.12, PowerShell, existing guarded native input helper.
**Spec:** docs/design_v0_3/DESIGNBOOK.md and LOREBOOK_v0.3.md; implementation explicitly authorized by the user's new request despite the archive's earlier discussion-only disclaimer.

## Global constraints
- Preserve existing CANON. Add only the approved Alash terminology and implementation authorization to the active LoreBook; retain the supplied documents intact.
- No foreign mods/assets; no game installation writes; no invented state/province IDs.
- Six ideological families retain compatible vanilla identifiers where necessary; native mechanics only, no new economy/migration interfaces.
- Negotiations require a recipient answer; refusals leave viable alternatives. No automatic annexation from another player's focus.
- Caspian geometry must be isolated in a recoverable branch/backup and tested with a restart. Until genuinely navigable, its naval branch must stay gated rather than pretend to work.
- No gratuitous unit-test suite. Static content validation and actual scenario/gameplay checks are the relevant verification.
- Use the second monitor; one game process; batch changes before launches; never regenerate ideas in a running debug session.

## Review focus
1. Receiver refuses or does not exist: no dangling target or blocked entire economy.
2. Country is landlocked/subject/at war: contextual branches remain sensible.
3. Incompatible political or strategic routes: mutual exclusions enforce actual choices.
4. Installed 1.19 doctrine/technology/DLC syntax: inspect original data before effects.
5. Missing flags/portraits and vanilla 1936 history/events: explicit provisional setup and no fabricated historical rulers.

## Execution
1. Archive intake, implementation ledger, authoring helpers and schema. Preserve source bytes; map every section to files/features and tests.
2. Independent content domains: USA/Japan; Alash plus regional/national campaigns; general tree, ideological families, research and doctrine adaptation. Agents own separate generator/output files and report integration contracts.
3. Parent integrates verified scenario territories, capitals/OOBs, new tags and bookmark country selection, reciprocal interstate chains A–F, initial spirits and starting wars/support.
4. Suppress incompatible vanilla focus/story content with justified narrowly scoped loading replacements. Validate IDs/references, localisation, graph reachability, alternative routes and installed state membership.
5. Batch full launch in -debug. Check selectable countries, actual tree selection and early decisions in several countries, negotiations including refusal, game time, logs and save/load. Record actual tested limits.
6. Isolate Caspian experiment only after the main multi-country setup loads. Do not represent port access or navigation as implemented until fleet/trade passage tests pass.
7. Final coverage ledger, playable instructions and remaining uncertainty. Deliver actual files and real verification, without calling proposals settled history.
