## Установка на другом ПК

Клонировать репозиторий (ветку `spike/caspian-navigation`) в папку `ashes_of_empires` внутри пользовательского каталога `Documents/Paradox Interactive/Hearts of Iron IV/mod`, либо подключить безопасным junction. Рядом создать `ashes_of_empires.mod`: скопировать содержимое descriptor.mod и добавить `path="ABSOLUTE/PATH/TO/ashes_of_empires"` с реальным путём нового ПК и прямыми слешами. Саму папку .git игра не использует. В Launcher создать отдельный набор только с этим модом. Запускать с `-debug`, подтвердить(D); dev.ps1 принимает `-GamePath`.

Сгенерированные игровые файлы автономны от Python и внешних резервных копий. Для разработки Pythonзависимости — numpy/Pillow; точный старый интерпретатор в AGENTS — лишь путь прежнего ПК, искать установленный Python заново. Скилл hoi4-modding лежит вне Git: на новом ПК проверить его доступность, не обещать наличие.

Запускать worldgenerator отдельно нельзя: он восстанавливает базовые истории и теряет поздние слои.

Текущие runtime-файлы и их Gitистория — безопасная точка продолжения до решения переносимости. Большие исходные игровые файлы из внешних backups, личные saves, кеши, credentials и crashdumps в публичный репозиторий не добавлялись. Для проверки истории используй TECH_NOTES и docs/verificationJSON, не выдавай предпросмотры данных за скриншоты игры.
